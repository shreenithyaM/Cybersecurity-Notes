## 🧠 Learning Approach

For each command or concept, I try to understand:

1. **What is it?**
2. **Why is it used?**
3. **What is the syntax?**
4. **What do the options/flags mean?**
5. **How does it work?**
6. **What happens when different inputs are given?**
7. **How can I practice it?**
8. **Where is it useful in Cybersecurity?**

---

## 🧪 Practice

These notes are meant to be practiced, not just read.

I use a Linux environment such as **Kali Linux** to run the commands and observe their behavior.

Example:

```bash
mkdir linux-practice
cd linux-practice
touch test.txt
echo "Hello Linux" > test.txt
cat test.txt
ls -l
```
