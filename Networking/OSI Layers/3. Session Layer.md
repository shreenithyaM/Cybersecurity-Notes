# Session Layer

## Functions
- Manages communication sessions between devices.
- Data is represented as _Data_.

### Responsibilities

#### 1. Session Establishment
Creates a connection between sender and receiver.

#### 2. Session Maintenance
Keeps the communication active.

#### 3. Session Termination
Ends the session after communication is complete.

#### 4. Authentication
Verifies user identity.

#### 5. Synchronization
Adds checkpoints during data transfer.

Example:  
If a 100 MB file transfer fails at 70 MB:
- Resume from checkpoint
- No need to restart from 0 MB

#### 6. Dialogue Control
It manages the communication (dialogue) between two devices by deciding **who can transmit data and when**.

##### **Types of Dialogue**
1. **Simplex**
    - Communication in one direction only.
    - Example: Keyboard → Computer.
2. **Half-Duplex**
    - Both devices can transmit, but not at the same time.
    - Example: Walkie-talkies.
3. **Full-Duplex**
    - Both devices can transmit simultaneously.
    - Example: Telephone calls.
---

### Common Protocols

| Protocol            | Purpose               |
| ------------------- | --------------------- |
| NetBIOS             | Session management    |
| RPC                 | Remote Procedure Call |
| PPTP                | VPN tunneling         |
| SMB Session Service | File sharing sessions |
| SIP                 | VoIP session setup    |
| SDP                 | Session description   |

### Security Threats
- Session Hijacking
- Replay Attacks

### Examples
- **Video call (Zoom / Google Meet / WhatsApp call)**  
    → Session is created, maintained, and closed after call ends
- **Online banking login session**  
    → You log in once and perform multiple actions without re-login
- **Downloading a large file**  
    → If internet breaks, session helps resume from last checkpoint
- **Remote login (SSH session)**  
    → Maintains continuous control between user and server
