# Physical Layer

- Transmits raw bits over the communication medium.
- Data is represented as _bits_
- Works with hub
---
## Functions
#### 1. Bit Transmission
- Sends data as 0s and 1s.
#### 2. Signal Encoding
- Converts bits into electrical, optical, or radio signals.
#### 3. Data Rate Definition
- Defines transmission speed.
#### 4. Physical Topology
Defines network layout:
- Bus
- Star
- Ring
- Mesh
---
#### Examples
- Hub
- Repeater
- Modem
- Cables
- Connectors
#### Security Threats
- Cable tapping
- Device theft
- Hardware destruction
- Rogue access points
---
### Transmission Media
#### Guided Media
- Twisted Pair Cable (UTP/STP)
- Coaxial Cable
- Fiber Optic Cable
#### Unguided Media
- Radio Waves
- Microwave
- Infrared

### Protocols/Technologies
| Standard  | Purpose                 |
| --------- | ----------------------- |
| RS-232    | Serial communication    |
| DSL       | Broadband communication |
| SONET     | Optical networking      |
| USB       | Device communication    |
| Bluetooth | Wireless communication  |
#### Examples
- Plugging in an **Ethernet cable** to connect internet
- Data traveling as **electrical signals in wires**
- Wi-Fi sending data as **radio waves**
- A **repeater boosting weak signals**
