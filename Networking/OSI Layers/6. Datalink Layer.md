# Datalink layer

- Provides **node-to-node delivery** within the same network.
- Data is represented as _frame_
- Uses MAC Address
- Works with Switch
---
### Functions
#### 1. MAC Addressing
- Uses physical (MAC) addresses.
- Each NIC has a unique MAC address.
Example: ```00:1A:2B:3C:4D:5E```
#### 2. Framing
- Converts packets into frames.
#### 3. Error Control
- Detects errors using CRC (Cyclic Redundancy Check).
#### 4. Flow Control
- Controls frame transmission rate.
#### 5. Access Control
- Determines which device can access the medium.
---
### Protocols
| Protocol              | Purpose                      |
| --------------------- | ---------------------------- |
| Ethernet (IEEE 802.3) | LAN communication            |
| Wi-Fi (IEEE 802.11)   | Wireless LAN                 |
| PPP                   | Point-to-Point communication |
| HDLC                  | WAN communication            |
| Frame Relay           | WAN technology               |
| ATM                   | Cell-based switching         |
| STP                   | Prevent switching loops      |
| VLAN (802.1Q)         | Virtual LAN tagging          |
### Devices
- Switch
- Bridge
- NIC (Network Interface Card)
### Security Threats
- ARP Spoofing/Poisoning
- MAC Flooding
- VLAN Hopping
#### Examples
- Sending a file between two computers on same Wi-Fi
- Data transfer within a **LAN (college, office network)**
- A **switch forwarding data** to the correct device using MAC address
- When your laptop connects to Wi-Fi, it uses MAC address to communicate
