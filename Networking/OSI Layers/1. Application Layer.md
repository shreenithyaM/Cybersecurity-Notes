# Application Layer

## Functions
- Provides services directly to the end user.
- Acts as an interface between user applications and the network.
- Allows applications to access network services.
- Data is represented as _Data_.
### Examples of Services
- Web browsing
- Email
- File transfer
- Name resolution

---

## Common Protocols

| Protocol | Purpose                    |
| -------- | -------------------------- |
| HTTP     | Web browsing               |
| HTTPS    | Secure web browsing        |
| FTP      | File Transfer              |
| SFTP     | Secure File Transfer       |
| SMTP     | Sending emails             |
| POP3     | Receiving emails           |
| IMAP     | Accessing emails on server |
| DNS      | Domain Name Resolution     |
| DHCP     | Automatic IP assignment    |
| Telnet   | Remote login (insecure)    |
| SSH      | Secure remote login        |
| SNMP     | Network management         |
| NTP      | Time synchronization       |

## Security Threats
- SQL Injection
- Cross-Site Scripting (XSS)
- Phishing
- Malware
- Credential Theft
### Example
When you open a website:
- Browser → HTTP/HTTPS
- DNS resolves domain name
- Data is sent through lower layers
