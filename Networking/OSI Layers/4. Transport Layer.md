# Transport Layer

- Provides **end-to-end communication** between processes running on different devices.
- Data is represented as _segment_.
- Works with router
- Uses Port Number

> [!tip]
> Data is divided into segments so it can be **sent easily in small parts and only the missing or damaged parts need to be resent**.

---
## Functions
### 1. Port Addressing
- Uses **port numbers** to identify applications/processes.
- Ensures data reaches the correct application.
Examples:
- HTTP → Port 80
- HTTPS → Port 443
- FTP → Port 21
- SSH → Port 22
### 2. Segmentation and Reassembly
- Large data is divided into smaller units called **segments**.
- At the destination, segments are reassembled into the original message.
Example:
```
Data 
↓
Segment1
Segment2
Segment3 
↓
Sent over network 
↓
Reassembled at receiver
```
#### 3. Flow Control
- Prevents a fast sender from overwhelming a slow receiver.
- Controls the rate of data transmission.
Example: ```Fast Sender  ---->  Slow Receiver```
Transport layer adjusts transmission speed.
#### 4. Error Control
- Detects transmission errors using **checksums**.
- Lost or corrupted segments can be retransmitted.
#### 5. Process-to-Process Communication
- Delivers data from one application process to another application process.
Example: ```Browser Process → Web Server Process```
---
### Protocols
| Protocol | Purpose                                                            |
| -------- | ------------------------------------------------------------------ |
| **TCP**  | Reliable, connection-oriented transport with ordered delivery      |
| **UDP**  | Fast, connectionless transport with no delivery guarantee          |
| **SCTP** | Reliable transport supporting multi-streaming and multi-homing     |
| **DCCP** | Unreliable transport with congestion control for real-time traffic |
### Security Threats
- Port Scanning
- SYN Flood Attacks
- UDP Floods
### Transport Layer PDU
**PDU (Protocol Data Unit) = Segment**
Structure:
```
+---------+---------+| Header  |  Data   |+---------+---------+
```
### Header Contains
- Source Port Number
- Destination Port Number
- Sequence Number
- Acknowledgment Number
- Flags
- Window Size
- Checksum
