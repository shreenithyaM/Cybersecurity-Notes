# Presentation Layer

## Functions
- Responsible for:
	1. **Translation**
	2. **Encryption**
	3. **Compression**
- Data is represented as _Data_.

### 1. Translation
Converts data between formats.
Example: ```Binary ↔ ASCII ↔ Unicode```

### 2. Encryption
Protects data from unauthorized access.
Example: ```Plain Text → Cipher Text```

### 3. Compression
Reduces data size for faster transmission.
Example: ```Large file → Compressed file```

---

## Common Protocols / Formats

| Protocol/Format | Purpose              |
| --------------- | -------------------- |
| SSL             | Encryption           |
| TLS             | Secure communication |
| JPEG            | Image compression    |
| PNG             | Image format         |
| GIF             | Image format         |
| MPEG            | Video compression    |
| ASCII           | Character encoding   |
| Unicode         | Character encoding   |

### Example
```
Shop Now   
↓
Compression   
↓
Encryption   
↓
01010100...
```

At the receiver:
```
01010100...   
↓
Decryption   
↓
Decompression   
↓
Shop Now
```
