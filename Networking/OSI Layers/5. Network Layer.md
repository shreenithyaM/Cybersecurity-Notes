# Network Layer

- Provides **logical addressing** and determines the best path for data to travel between networks.
- Data is represented as _packet_
- Works with router
- Uses IP Address
---
### Functions
#### 1. Logical Addressing
- Uses IP addresses to identify devices.
- Source and destination IP addresses are added to packets.
Example:
```
Source IP: 192.168.1.10
Destination IP: 8.8.8.8
```
#### 2. Routing (Path Determination)
- Finds the best route from source to destination.
- Routers operate at this layer.
#### 3. Packet Forwarding
- Sends packets to the next hop toward the destination.
#### 4. Fragmentation
- Breaks large packets into smaller packets when required.
---
### Protocols
| Protocol | Purpose                              |
| -------- | ------------------------------------ |
| IPv4     | Logical addressing                   |
| IPv6     | Logical addressing                   |
| ICMP     | Error reporting & diagnostics (Ping) |
| IGMP     | Multicast management                 |
| OSPF     | Routing protocol                     |
| RIP      | Routing protocol                     |
| EIGRP    | Routing protocol                     |
| BGP      | Internet routing protocol            |
| IPsec    | Secure IP communication              |
#### Devices
- Routers
- Layer 3 Switches
#### Security Threats
- IP Spoofing
- ICMP Attacks
- Route Manipulation
#### Examples
- Sending a message on WhatsApp → data is routed through many networks
- Typing a website URL → IP address is used to locate server
- Google Maps finding route → similar idea to network routing
- Using **ping command** → checks if a system is reachable
