# Cybersecurity Notes

A structured collection of technical concepts and practical knowledge required to build a strong foundation in Cybersecurity.

These notes cover the core areas that a cybersecurity professional needs to understand, including **Networking, Linux, Operating Systems, Bash, JavaScript, Backend, HTTP, APIs, Databases, Cryptography, Authentication, Web Security, and Security Tools**.

The focus is not on memorizing theory, but on understanding **how things work, why they matter, how they are used in real systems, and how they relate to cybersecurity**.

Each topic will be documented with practical examples, security relevance, common mistakes, attack concepts, defensive concepts, and hands-on practice where applicable.

**Goal:** Build a strong technical foundation that allows me to understand, analyze, secure, and test computer systems and applications.
